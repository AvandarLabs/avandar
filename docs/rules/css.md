# CSS rules

## Comments

- Use single-line block comments only when the full comment fits on one line:

  ```css
  /* Comment here */
  ```

- Use leading `*` markers for multi-line block comments. Put the opening
  `/*` and closing `*/` on their own lines:

  ```css
  /*
   * Comment here lorem ipsum bla bla
   * More comment lorem ipsum bla bla
   */
  ```
