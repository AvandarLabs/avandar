# Diff guide

1. Resolve the current artifacts and read reviewed state, or initialize it.
2. Apply mark-reviewed instructions.
3. Regenerate the guide, per
   [Regenerating the guide](../contracts/guide.md#regenerating-the-guide).
4. Update the summary or test plan only when stale. Never touch the
   walkthrough.
5. Briefly report the reviewed and remaining counts without pasting the guide.

Do not change source files, commit, push, or post comments in Diff guide mode.
