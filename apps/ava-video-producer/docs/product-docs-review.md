# Reviewing product documentation for a video

Read the current Avandar source and relevant documents from the enclosing
workspace. Record the revision and distinguish marketing language, design plans,
implemented behavior, and inspected runtime results. Internal audits and working
notes belong under `.videos/<project>/`, which Git ignores.

The migration's earlier documentation audit is retained locally under
`.videos/migration-archive/docs/`. It is historical context, not a requirement for
building or using the public examples.
