# Figtree font

Figtree is Avandar's brand typeface. `figtree-latin.woff2` is the unchanged
Latin variable font (weights 300 to 900) from
`@fontsource-variable/figtree` 5.3.0, the same package the product loads. It
is bundled locally so live previews, the showcase, and MP4 exports do not
depend on a font-CDN request.

Source: `@fontsource-variable/figtree/files/figtree-latin-wght-normal.woff2`

package's `LICENSE`.
