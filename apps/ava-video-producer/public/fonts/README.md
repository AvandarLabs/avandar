# Geist font

`geist-latin.woff2` is the unchanged Latin variable font previously loaded by
`@remotion/google-fonts/Geist` 4.0.516. It is bundled locally so live previews
and MP4 exports do not depend on a Google Fonts network request.

Source: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFU.woff2
